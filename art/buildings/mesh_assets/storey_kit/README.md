# Derived exterior storey kit

384 GLBs: 128 authored designs × three LODs. Each file has ground, upper and
crown scenes (Scene0/1/2). Shared textures live in textures/. Built from our
existing front_modules/ and models/ with tools/build_architecture_kit.py.
Original source GLBs are unchanged; MANIFEST.json records both hashes, bounds,
heights and triangle counts. SHA256SUMS lists actual derived media.

Creator: RoadDash contributors. License: repository MIT (../../../../LICENSE).
Sources and notices: parent README.md, PROVENANCE.md and existing catalog records.
No retail texture pixels or concept-sheet images are embedded in this kit.
Existing original own-authored material bytes are deduplicated by SHA256.
Draft art/style resemblance and wider production acceptance remain open.

Geometry is cosmetic. Runtime shells own all physical collision. See
../../../../docs/art/BUILDING_GRAMMAR.md and the Part04 test receipt for limitations.
