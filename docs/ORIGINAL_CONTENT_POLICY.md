# Original-content and reuse policy

Part 00 policy, 2026-10-30. Public RoadDash is an independently authored spiritual
successor. No EA license is asserted. No original binary, sprite, music, voice,
character data or course data is required, imported, or distributed.

1. Use public historical documentation for behavior research only. Attribute
   documentary confidence; do not assert a behavior was played/tested when only
   described in a reference README. No binary parity target.
2. Code requires an explicit verified license and exact source revision before
   adaptation. Preserve notices and document actual copied files/changes.
3. Media requires author, exact license, source URL, modifications, redistribution
   permission, hash or generated-source pointer, and attribution. Code licensing
   does not automatically license bundled art or music.
4. Unknown-license assets stay out of runtime and release packages. The supplied
   blueprint and documentation screenshots are planning material, not gameplay
   media or evidence of a license to reproduce protected expression.
5. The current runtime uses original procedural geometry/colors/audio and Bevy's
   OFL-licensed Fira Mono subset. External LUT media is disabled; Reinhard needs
   no imported LUT. Package source/shader licenses are tracked separately.
6. Before any public commercial release, review title/trade dress, contributor
   rights, trademarks/brands, all runtime media and notices. This engineering
   inventory is not legal counsel or release signoff (P16).

See third_party/REPOSITORIES.md, ASSETS.csv and licenses/ for the current intake
records. CI checks completeness, file hashes and declared dependency licenses;
it cannot independently prove ownership or replace manual rights review.
